# NEOMEN Architects — Premium Architecture & Interior Design Website

An ultra-luxury, single-page web application inspired by [Neomen Studio](https://www.neomen.in/).

**Live Website**: [https://pallak-devi.github.io/neomen-architects/](https://pallak-devi.github.io/neomen-architects/)

## Features

1. **Cinematic Hero Slider (6 Architectural Slides)**: Full-bleed architectural showcase featuring curated photography from Unsplash, smooth 700ms cross-fading, dark glassmorphism Previous/Next chevron controls, interactive bottom indicator bars with active states, editorial slide counter, keyboard navigation, and automatic 6-second rotation with instant manual override.
2. **Key Stats Dashboard**: Minimalist statistics bar highlighting projects completed, global studios, and architectural awards.
3. **Filterable Selected Portfolio**: Interactive portfolio grid with filters for *Residential*, *Interiors*, and *Commercial* projects, featuring detail modal popups.
4. **Interactive Material Atelier**: Real-time texture and finishes preview selector showcasing *Italian Travertine*, *Patinated Brass*, *European White Oak*, and *Board-Formed Concrete*.
5. **Project Investment Estimator**: Dynamic area slider and finish tier calculator delivering instant cost estimates in Indian Rupees (Cr).
6. **Editorial Journal**: Architectural design philosophy articles and trend insights with curated editorial imagery.
7. **Bespoke Consultation Portal**: Responsive booking form with studio addresses across New Delhi, Mumbai, Bengaluru, and Dubai.

## File Structure

- `index.html`: Complete, self-contained single-page website with Tailwind CSS (CDN), Lucide Icons, Cormorant Garamond / Plus Jakarta Sans fonts, and embedded JavaScript.
- `README.md`: Project summary, live deployment URL, and setup instructions.

## Usage

Simply open `index.html` in any web browser, or view the live deployment at [https://pallak-devi.github.io/neomen-architects/](https://pallak-devi.github.io/neomen-architects/).
